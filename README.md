# Python +12V 電壓資料判讀工具

使用 Python 標準函式庫讀取 CSV，依設定的 +12V 參考範圍進行 PASS／FAIL／INVALID 分類，並輸出逐筆結果、統計摘要與分析報告。

> 本專案展示資料處理與判讀邏輯，不是 PSU 硬體認證工具。示範資料為人工建立，不代表實際 PSU 量測結果。

## 專案目的

將電壓資料判讀流程自動化，練習：
- CSV 檔案讀寫與必要欄位檢查。
- 邊界值判定與無效數據處理。
- 命令列介面設計。
- 統計摘要與 Markdown 報告產生。
- 保存輸入副本，讓分析結果可以追溯。

## 功能

- 支援示範模式 `--demo` 與自訂輸入 `--input`。
- 每次執行先進行 9 個電壓分類自我測試。
- 識別空白、非數字、NaN 與無限值。
- 檢查必要 CSV 欄名、無資料列及資料列欄位溢出。
- 輸出 PASS／FAIL／INVALID 筆數。
- 計算有效電壓的最小值、最大值與平均值。
- 以時間戳建立独立輸出資料夾，保存每次分析結果。

## 判定規則

本專案採用 **11.40～12.60 V，含上下邊界**作為 +12V 的檢查範圍。

| 結果 | 條件 |
|---|---|
| PASS | 電壓位於設定範圍內，包含上下邊界 |
| FAIL | 有效數值低於下限或高於上限 |
| INVALID | 空白、非數字或非有限數值 |

PASS 僅代表該筆讀值符合設定範圍，不代表整顆 PSU 正常或符合完整 ATX 規範。

統計包含 PASS 與 FAIL 的有效數值，排除 INVALID。

## 使用環境

- Python 3，建議使用 3.10 或更新版本。
- 僅使用標準函式庫，不需安裝第三方套件。
- 執行時需具備專案資料夾的寫入權限。

## 快速開始

下載專案後，在含有 `analyze.py` 的資料夾開啟終端機。

執行人工建立的示範資料：

    python analyze.py --demo

Windows 若使用 Python Launcher，也可執行：

    py analyze.py --demo

分析符合本工具格式的 CSV：

    python analyze.py --input measurements.csv

`--demo` 與 `--input` 必須擇一使用。

## CSV 輸入格式

CSV 必須包含下列七個欄位，建議使用 UTF-8 編碼：

| 欄位 | 用途 |
|---|---|
| sample_id | 樣本識別碼 |
| elapsed_s | 相對經過時間，單位為秒 |
| dut_id | 待測物或監測系統識別碼 |
| scenario | 測試情境 |
| connector | 接頭或感測位置 |
| voltage_v | 要判讀的電壓，單位為 V |
| notes | 資料來源、限制或其他備註 |

電壓欄請填寫如 `12.00` 的數值，不要附加 `V` 單位。

本工具目前只判讀 `voltage_v`，不驗證其他欄位是否填寫完整或內容是否正確。

**不能直接輸入整份 HWiNFO 原始 CSV。**若使用軟體感測資料，需先轉換為上述格式，並在備註中標明資料來源。此版本不適用於 +5V、+3.3V、CPU 核心電壓等不同電壓軌。

## 示範案例與預期結果

以下為程式內建的人工示範資料，不是硬體實測：

| 輸入 | 預期分類 |
|---|---|
| 12.00 | PASS |
| 11.40 | PASS |
| 12.60 | PASS |
| 11.39 | FAIL |
| 12.61 | FAIL |
| 空白 | INVALID |
| abc | INVALID |
| NaN | INVALID |

執行示範模式時，主要預期輸出為：

    Software self-test: 9/9 PASS
    Data rows: 8
    PASS: 3 | FAIL: 2 | INVALID: 3

有效數值的預期統計：
- 筆數：5 筆。
- 最小值：11.390 V。
- 最大值：12.610 V。
- 平均值：12.000 V。

自我測試另含 `inf` 案例，所以自我測試為 9 筆，示範 CSV 為 8 筆。這 9 個測試針對電壓分類函式，不代表所有檔案讀寫與報告功能都有自動化測試覆蓋。

## 輸出檔案

每次分析會在程式所在資料夾的 `outputs/` 下建立獨立目錄：

    outputs/
    └── demo_時間戳/
        ├── source.csv
        ├── results.csv
        └── report.md

| 檔案 | 內容 |
|---|---|
| source.csv | 本次輸入檔的副本 |
| results.csv | 原始七欄、上下限、逐筆分類與原因 |
| report.md | 筆數、統計、資料判定與限制說明 |

使用 `--input` 時，輸出目錄前綴為 `input_`。

其他自動產生的檔案：
- `measurements.csv`：若不存在則建立待填模板；電壓欄為空白，不是量測成果。
- `demo_cases.csv`：每次示範模式會重新建立，請勿在此檔保存正式量測資料。

## 限制

- 不驗證資料真實性、感測器準確度、接線或量測方法。
- 不自動判斷輸入資料是模擬資料、軟體感測或電表量測。
- 不檢查樣本識別碼是否重複、取樣間隔或必要筆數。
- 不按待測物、情境或接頭分組統計；有不同群組時應分檔分析。
- CSV 檢查為基本檢查，不是完整結構驗證。
- 未納入量測不確定度，顯示三位小數不代表儀器具有相同精度。
- 不分析電流、功率、漣波、快速瞬態、保護功能或可靠度。
- 即使所有讀值均為 PASS，也不能證明整顆 PSU 正常。
- FAIL／INVALID 會記錄於輸出內容；目前不以不同程序退出碼區分這些資料判定結果。

## 專案定位

本專案聚焦於 **Python 資料處理、邊界測試、異常值處理與結果可追溯性**。

HWiNFO 實際監測資料與硬體情境分析另行整理，避免將人工示範資料與實際監測成果混為一談。
